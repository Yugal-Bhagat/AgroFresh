# AgroFresh 

## Structure

- `frontend/` - React + Vite frontend
- `backend/` - Node.js + Express + MongoDB backend

## Setup

### Frontend

\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`

### Backend

\`\`\`bash
cd backend
npm install
npm run dev
\`\`\`

## Environment Variable
Backend `.env` file 
\`\`\`
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
\`\`\`
